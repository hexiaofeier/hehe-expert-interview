# 家用全自动咖啡机访前背景与来源

编制日期：2026年10月31日。用途：本次用户访谈 Skill 试跑的主持人背景资料。

本次拟研究中国大陆家庭使用的咖啡豆式全自动咖啡机，覆盖购买、持续使用、闲置或退货，以及认真考虑后未购买。下列三项官方材料只用于辨认可能出现的操作阶段及配置差异，不承担市场判断。品牌、型号和功能名称留在本文件；受访者版提纲不展示品牌或功能清单。

本文件为公开背景版，保留来源、原文定位和提问用途。

## 一、三项已读取的官方材料

### S1：德龙中文快速入门指南

- 官方文件：[快速入门指南，文件编号 ZH-5713250392](https://dls.delonghigroup.com/files/pdfmanuals/ZH-5713250392.pdf)。文件末尾列有制造商中国大陆官网，文件标识为 `5713250392_02_0423`；原文共16页。
- 原文定位：在 PDF 内搜索“首次使用”“制作黑咖热饮”“安装牛奶容器”“清洁牛奶容器”。该快速指南以操作图为主，本次只使用能辨认的章节和文字，不从图中推断未验证的按钮步骤。
- 窄事实：该指南把初次设置、饮品制作、奶容器安装和奶容器清洁列为不同任务；奶饮制作涉及奶容器，不能据此推定所有豆式全自动机都有同样的奶系统。
- 转为问法：先问“请从上次想喝咖啡开始，一直讲到您把机器收拾好，实际做了哪些事？”受访者自然讲到加奶或制作奶饮后，再追问实际如何完成、如何收拾。

### S2：德龙 ECAM350.25 全自动机中文使用说明书

- 官方文件：[ECAM350.25 使用说明书](https://dls.delonghigroup.com/files/docs/5/A1-57132C7951.pdf)。为繁体中文版本，含台湾产品标识；用于确认操作形态有差别，不代表中国大陆同型号、同配置或同保养规则。
- 原文定位：文件内页码9，6.4“設置設備”；页码12，16.3“使用咖啡豆製作飲品”；页码14—15，第18节及18.2“蒸汽管使用後清潔”；页码16—17，第20节；页码18，第21节；页码19—20，第23节。正文内部部分交叉引用的章节号有错位，核查时以章节标题定位。
- 窄事实：此机型示例以蒸汽管处理奶，与 S1 的奶容器流程不同；日常残渣处理、可拆部件清洁、除垢分别出现；软水过滤器在配件说明中带有机型限制，不能默认每台机器都有。说明书还区分停用后重新使用与平日操作。
- 转为问法：维护先问“最近一次需要处理机器的提示、清理或保养，发生了什么？当时是谁处理的？”仅对本人实际做过的部分追问具体经过。恢复使用先确认是否真的恢复；没有恢复的人只问停用后状态和当前打算，不要求讲述“恢复后的第一杯”。

### S3：飞利浦官方滤水器支持说明

- 官方网页：[飞利浦浓缩咖啡机提示我在安装 AquaClean 滤水器后进行除垢](https://www.philips.com.cn/c-t/XC000017671/aquaclean)。页面下方列有适用型号，并非面向所有咖啡机。
- 原文定位：页面中“未及时更换 AquaClean 滤水器”“AquaClean 滤水器尚未激活”两节。
- 窄事实：在该适用范围内，装入滤水器与在机器上激活属于不同环节；更换时点、激活状态和除垢提示存在联系。不能把滤芯、除垢用品写成所有人都购买、使用或认识的东西。
- 转为问法：先问“除了咖啡豆和日常用水，您实际还买过或换过什么机器用的东西？最近一次是怎么决定和处理的？”受访者自己提到某类用品后再追问；未用过、他人处理或不清楚均作为有效回答，不读出耗材清单提醒。

## 二、用于提纲的任务阶段与条件分支

下列阶段是根据上述说明整理的访谈设计框架，是研究者的组织方式，不是已证实的用户经历。实际访问须先确认受访者到过哪些阶段，再沿最近一次具体事件展开。购买及家庭分工的分支来自本次研究范围，不由制造商手册证明。

可能的阶段为：考虑及决定 → 到家与安排位置 → 初次准备和学会操作 → 平日制作与饮用 → 补充及收拾 → 较少发生的保养或求助 → 停用、处置或恢复。每一阶段都允许未发生、他人完成或记不清。

| 先确认的实际情况 | 适用问法或跳转 |
|---|---|
| 本人参与选购、他人购买本人使用、他人购买且本人未使用 | 先问机器怎么来到家里、谁参与决定、本人做过什么；本人未参与选择时不追问其“当时如何比较”，可记录所知来源。 |
| 已购买但未开箱、未设置，或本人没经历首次使用 | 问实际停在何处及原因；首次使用由别人完成时问本人何时开始接触，不要求代述首次操作。 |
| 用机器做过含奶饮品；有相关配置但没用过；没有相关功能；使用另外的器具；本人不清楚 | 先开放询问实际饮品及做法；只有实际用过相关步骤的人进入奶饮制作和清理追问。其余人转回自己的制作过程。 |
| 亲自清理、由家人处理、由服务人员处理或未处理过 | 只对本人经历追问操作细节；对家庭分工可问谁负责、怎样商量及对本人使用的影响。 |
| 买过或换过相关用品；从未买过；由别人负责；不清楚 | 按本人主动提及的用品追问最近一次获取、辨认、使用及影响，不预设有滤芯、清洁片、奶路用品或润滑用品。 |
| 持续使用、频率下降、已经闲置 | 先问最近一次实际使用和变化时间；不把低频直接等同于不满意或闲置。 |
| 闲置后恢复、尝试恢复未成、一直未恢复 | 分别问那次恢复经过、尝试停在哪一步、停用后的现状；未恢复者跳过恢复体验问题。 |
| 已退货、转赠或出售；仍在家中 | 问实际处置经过和前因后果；未使用即退货者跳过使用质量评价。 |
| 考虑后未买 | 围绕最近一次真实考虑、已做的了解、决定停下的时点及现在解决咖啡需求的方法；不问实际设置、清洁或故障经历。 |

## 三、背景材料的用途

三份官方材料用于确定相应产品的任务及配置差异；实际使用、购买动机和结果由后续访谈取得。不同地区与型号的配置和保养周期不直接移植为所有受访者的题目前提。

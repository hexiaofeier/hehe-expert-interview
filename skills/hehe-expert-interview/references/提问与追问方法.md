# 提问与追问方法

用本文件把已经确定的研究问题写成能直接问出口的主问，再为重要回答准备条件追问。按本轮任务选用方法，保留取得关键经营信息、行为细节和有价值判断的力度。

## 1. 先写自然、完整的主问

1. 每个主问对应一项清楚的信息任务，说明必要的对象、场景或期间，让受访者知道从哪里回答。用他的工作或生活语言表达研究概念。
2. 主问一次推进一个中心问题，相关维度放入追问。请对方讲过程可以是一个主问，具体参与者、数字和原因再依回答展开。
3. 先取得受访者自己的描述，再用主持提示补充遗漏。候选答案、材料疑点、研究假设及例子放在主持提示，便于主持人核对。
4. 对重要业务、数字、失败和利益取舍直接发问；必要时说明研究用途，再给出适合对方知情与披露范围的回答方式。

可使用以下问法结构，但替换成当前研究对象和已确认范围：

- 具体经历：“请回想最近一次发生这类问题的情况，当时您是怎样处理的？”
- 工作流程：“请选一个您亲自负责的项目，讲一下从启动到目前结果的经过。”
- 决策与取舍：“这次最终选择这个方案，起决定作用的是什么？”
- 指标解释：“这张表里的新增客户是怎样统计出来的？”
- 判断与机制：“您认为这类业务接下来会怎样变化？您主要依据哪些已经看到的情况？”

## 2. 按回答启用追问，写清触发条件

每个核心主问下只放与该任务有关的追问，用“若提到……”“若尚未发生……”“若数字是估算……”说明何时启用。优先补足会改变判断的缺口。

| 回答表现 | 下一步追问 |
|---|---|
| 只有“方便、效果好、领先、客户认可”等评价 | 请讲一件具体事情；发生了什么变化，体现在哪个结果或指标 |
| 讲了结果但省略过程 | 当时先发生什么，谁做了什么，哪个节点改变了结果 |
| 将多类情况合在一起 | 哪类对象、场景或时期不同；请选主要两类分别说明 |
| 没有购买、没有采用或中途停止 | 最近一次认真考虑到哪一步，为什么停下，后来怎样完成原任务 |
| 给出数字或预测 | 转入数字口径、来源和估算追问；预测再问成立条件 |
| 超出本人亲历范围 | 这部分是从哪里了解到的；谁直接负责，是否有可核对的材料 |
| 与已读资料或前访不同 | 先核对象、范围、期间与阶段，再请解释仍未对上的差异 |

追问取得足够信息后回到主线。对方已经讲清的内容直接承接，不把所有备选问题机械问一遍。

## 3. 用事件、流程、替代和依据展开分析

### 具体事件与业务流程

- 让受访者选一件实际发生、本人参与且与研究问题有关的事件，明确发生时间、对象和本人职责。
- 沿时间线问触发、原来做法、关键行动、参与角色、交接、决定、结果与后续；哪个步骤最影响结局，就在该处深入。
- 涉及组织流程时追谁提出、谁执行、谁有预算或决定权、谁能否决；制度规定与这次实际做法分别问。
- 遇到问题或失败，问最早何时发现、造成什么损失、尝试过什么、谁处理、结果怎样。把“痛点”落实到时间、成本、收入、风险或任务结果。

### 替代方案与效果比较

- 问采用之前怎样完成任务，还认真考虑或用过什么方案，为什么保留、淘汰或更换；没有购买也能取得真实选择信息。
- 比较前对齐任务、对象规模、时期和评价指标，追原有基线与现在结果，分清哪些变化由方案带来，哪些同时受人员、流程或环境影响。
- 对优势问它改变客户什么结果、客户愿为何付费；对切换问迁移、培训、兼容、停工和重新验证等实际成本，按回答选择相关项。

### 判断、原因与重要反例

- 对行业、技术或未来判断先问依据：亲历项目、持续观察、统计资料还是推算；请提供最能说明问题的案例或出处。
- 继续问“哪些条件使这个结果出现”“还有什么解释”“哪些群体或场景不同”，把机制与适用范围问清。
- 对决定研究结论的关键假设，补问不成功、不采用或变化相反的实例；追差异怎样形成，什么结果会使受访者修改判断。
- 未来计划按驱动拆解，例如客户数、价格、份额、频次或新品贡献；追最关键的资源、节点与不确定条件，以及条件改变后预计怎样调整。

## 4. 数字先问清口径，再用于比较和计算

对会进入结论、比较或模型的核心数字，取得下列信息；普通背景数字按用途取舍。

| 要素 | 直接追问什么 |
|---|---|
| 对象与范围 | 哪个企业或品牌、产品、客户、地区和场景；包括和不包括什么 |
| 定义与状态 | 是存量还是新增、累计还是去重、注册还是活跃或付费、订单还是收入、出货还是终端在用 |
| 期间与时点 | 哪个年度、季度或月份，截至哪一天；历史实绩、当前状态还是未来预测 |
| 单位与计价 | 数量、金额、频次或时长；币种、含税与否；按件、客户、项目还是年度计费 |
| 分子、分母与公式 | 比例中的分子和分母各是谁、来自哪段时期；转化率是否属于同批对象；指标如何算出 |
| 来源与知情基础 | 本人负责、系统报表、合同、财务或测试记录、公开资料、听闻还是估算；可对应哪份记录 |
| 构成与差异 | 能否按产品、客户、地区或渠道分解；总量与分项是否对应，主要差异来自哪里 |

需要估数时按可回答程度推进：先取准确数；不能准确提供就问最可能区间；再尝试比例、量级、典型项目或分项估算。每一步都保留对象、期间和算法。

- 问“您怎样得到这个估计？用了哪些底数和假设？”再问哪些参数最不确定，什么条件会使上下限改变。
- 需要规模参数时可沿“对象数量×采用比例×单次或单体用量×单价”拆问；单位换算、重复计数和更新周期逐层澄清。
- 客户数量占比与收入贡献占比分开；交易总额与企业收入分开；各转化环节沿用各自分母，熟悉的指标名也要核公式。
- 对重要结果选一条适合的核对关系，例如分项加总、数量乘价格、采购支出对应供应收入、增长对应人员或产能；不一致时先问统计差异。
- 明确区分真实历史、经营目标、合同支持部分、在谈机会和专家预期，并记录其各自依据。

需要受访者查表时，把指标名、定义、期间、单位和所需分类写成简短数据请求，现场重点讨论口径、原因和异常。

## 5. 商业核验分清合作、履行、收入与现金

先用一个具体项目确认实际交易链和当前状态，再选与研究目的有关的节点深入。不同业务的先后顺序、付款方式和收入政策，请受访者按实际说明。

| 节点 | 核实的具体内容 |
|---|---|
| 需求与意向 | 谁提出什么需求，是否已有预算或采购计划，合作意向附带什么条件 |
| 合同或订单 | 购买什么、数量与金额、有效及取消条件、是否仍需验证或其他审批 |
| 交付与实施 | 已交付到哪一步，何时交付，谁负责安装、集成或培训，延期原因是什么 |
| 验收与上线 | 谁验收、标准和否决项是什么，是否通过，有无附条件接受或整改，是否真正投入使用 |
| 确认收入 | 哪个期间、按什么政策和条件确认，包含哪些产品或服务，与合同和交付表怎样对应 |
| 开票、应收与回款 | 合同付款节点、实际开票与到账、尚欠多少或占比、是否超过信用期及原因 |
| 持续使用与续购 | 现在谁在使用、频次和结果如何，是否复购或续约，下一次选择需要什么条件 |

若受访者说“已落地”或“已量产合作”，追问他具体指哪个状态。对增长预测，将订单分状态、客户导入、交付验收、确认收入和回款时间连接起来，再问研发、供应、人员及资金是否支持。

## 6. 技术核验连接使用条件、测试与量产阶段

从已确认场景的实际任务和最低要求切入，再问当前方案达到什么水平及依据，避免只收集一组脱离用途的领先指标。

- **指标定义：**单位、测量方法、典型值或范围是什么；与哪些方案比较，对客户结果有多大影响。
- **测试条件：**什么产品或版本、环境、负载、输入材料和配置，样本数量、测试持续时间及重复情况如何；比较方案是否处于相同条件。
- **证据阶段：**数据来自仿真、实验室、样品、自有演示、客户试点、正式采购部署还是持续量产；由谁测试，有什么评测或客户记录。
- **工程取舍：**性能提高是否伴随成本、功耗、尺寸、可靠性、良率或交付变化；哪些场景达不到要求，故障后怎样处理。
- **导入与量产：**客户从样品到使用有哪些验证和否决项；稳定生产需要哪些工艺、供应、产能、认证或系统条件，当前还卡在哪里。
- **下一阶段：**尚需完成什么任务、由谁验证、需要多少时间和资源；延期、失败或替代路线成熟时怎样调整。

有路线图、评测、量产记录或销售材料时，将同一产品与时期对齐，询问计划节点、当前阶段、实际交付和收入为何一致或不同。重要技术判断继续向需求端核最低要求和实际评价。

## 7. 敏感或暂时答不出的信息，换一种可用问法

先确认是记不清、没有权限、没有记录，还是不便披露，再选择能保留研究价值的方式：

- 精确金额不便提供时，问区间、同比变化、比例或典型项目；比例仍需问清分母与时期。
- 客户名不便提供时，问行业、规模、应用、合作阶段和集中度，以匿名案例解释实际交易。
- 成本或毛利不便提供时，问主要构成、变化方向、差异来源，以及哪些因素最影响结果。
- 内部数据无法现场取得时，问可提供的汇总、公开出处或适合补问的角色，并约定可行的后补内容。
- 对方选择跳过时记录缺口与可替代证据，继续其他主题；用途和披露安排采用本项目真实能够履行的约定。

## 8. 把追问结果记录成可继续核查的材料

在提纲中为核心问题预留：`题号与研究问题｜回答要点｜具体事件和时间｜事实描述/经验判断/预测/建议｜本人知情范围｜数字及口径｜来源或可提供材料｜差异与待核事项`。

数字记录补上范围、期间、单位、分母、公式及准确数或估数；技术记录补上测试条件和阶段；交易记录补上节点与状态。记录未知与不便披露的具体原因，便于选择后续取证办法。

每项待核事项写清：缺什么、影响哪项研究问题、拟补哪份材料或问哪类角色、下一步怎样澄清。主持人据此准备补访和资料请求，后续分析可以区分受访者描述、可核记录与研究者判断。

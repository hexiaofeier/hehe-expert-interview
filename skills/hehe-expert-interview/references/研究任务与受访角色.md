# 研究任务与受访角色

每次设计先用本文件确定本轮要解决什么、已有材料能支持什么、应向谁取得哪些信息。简单单角色任务可用几段说明完成；多角色项目再用分工表展开。

## 1. 把研究目的转成可回答的任务

1. 写明成果使用者要作的具体判断，例如是否进入某市场、增长目标能否实现、采购为何未转为使用，或产品应优先解决哪项任务。
2. 确定对象与范围：哪家企业或哪类产品、哪些人或组织、哪个场景、地区和时期。ToB、ToC是背景信息，题目仍由本轮任务与受访者经历决定。
3. 从用户材料中提取最影响判断的研究问题，说明每项缺少的是事实、参数、过程、原因解释还是经验判断。信息不足时先形成核心主线，将会改变角色或题组的歧义标为待确认。
4. 选择下表中与本轮有关的任务，可组合；每项任务都应指向拟取得的信息，不把整张表扩成一份全问提纲。

| 本轮任务 | 应取得什么 | 优先考虑的角色 |
|---|---|---|
| 开题探索、行业与竞争研究 | 对象定义、细分、参与者差异、供需机制、已发生的变化及典型案例 | 行业专家、不同供需环节、区域或细分市场知情者 |
| 市场规模与经营参数补充 | 数量、单价、渗透率、单耗、频次、更新周期及推算依据 | 业务、财务、渠道、下游采购及掌握相应参数的专家 |
| 企业画像、商业模式与商业尽调 | 业务怎样运作，订单质量、交付能力、客户关系和增长所需资源 | 高管与相关职能、客户、供应商、渠道、竞对 |
| 组织采购与实际使用研究 | 需求、预算、选型、决策、实施、验收、实际使用及续购之间的关系 | 需求提出者、采购、预算或审批方、使用者、供应或实施方 |
| 技术路线与工程化核验 | 场景最低要求、指标条件、路线取舍、验证阶段、量产与导入障碍 | 对应技术专家、研发、工艺或制造、下游技术及采购人员 |
| 用户需求、行为与体验研究 | 具体任务、触发、原来做法、选择与使用过程、替代和停用原因 | 实际使用者、购买者、付款者，以及与任务相关的未买或流失人群 |
| 产品概念与方案试探 | 原有行为和需求、新方案的采用条件、与现有替代的取舍 | 具有相关任务经历的现有或潜在用户、采购和使用角色 |
| 组织、战略与绩效诊断 | 目标、职责、工作交接、资源、激励如何影响实际结果 | 高管、业务与职能主管、一线执行者及协作部门 |
| 案例学习、结果解释与补证 | 一次事件如何发生，已有发现为何出现，尚缺哪些事实或不同条件 | 事件当事人、前访对象、对应细分群体及能解释机制的专家 |

任务相同也要看阶段：首次探索先建立对象与机制，验证型访谈围绕具体主张和异常点，补访围绕尚未清楚的事项。

## 2. 先读已给材料，再补设计提纲所需的背景

1. 先读取用户给出的研究需求、产品或企业说明、已有提纲，以及相关前访、问卷或模型。列出实际读到的文件与版本；材料中的表格、附录、批注和图示若承载关键前提，也要读取。
2. 按研究问题选择材料：组织职责图用于找知情部门，产品清单与路线图用于分清对象，合同或订单表用于核交易状态，预测模型用于拆增长假设，评测与专利清单用于准备技术评阅问题。
3. 将材料分成四种用途：有来源支持的背景、待确认的主张、彼此冲突的表述、目前没有信息的事项。材料中的已有回答与研究者猜测分别标明，避免写进新问题的事实前提。
4. 背景不足时，使用当前可用的检索、原文读取或用户材料，为对象定义、基本流程、角色职责和关键术语补查必要信息。以足够写出具体问题为止，不把完整行业研究设为提纲设计的前置任务，也不依赖特定其他Skill安装。
5. 对能由现有材料明确回答的基础事实，直接用于定制问题；需要确认其变化、实际执行或口径时再问。把有限访谈时间留给材料解释不了的过程、条件、差异与判断。

把未知和冲突转成问题时，逐项完成：

- 写出未知如何影响本轮判断，再确定谁有经历或记录可回答。
- 定位冲突涉及的文件、页表、对象、期间和指标；先检查是否只是分类、范围或更新时间不同。
- 为仍需澄清的差异准备中性主问，例如“请说明这两份材料各自统计了哪些业务，怎样对应到同一时期的产品分类”。具体出处放主持提示。
- 将同一事项拆成事实、解释和后续条件：目前是什么状态，差异怎样形成，接下来需要发生什么。
- 对暂时无法获得的关键材料，照常起草可执行部分，列明需要补的材料、拟问角色及它会改变哪些题组。

准备结果应能简明回答：本轮最重要的待证问题是什么，每项准备向谁取得什么，而不只是列一包背景资料。

## 3. 保留三种模式，再确定实际知情范围

| 模式 | 主要信息位置 | 进一步核实 |
|---|---|---|
| 行业专家 | 跨企业、环节或项目的机制、比较与经验判断 | 做过哪些相关工作，覆盖哪些地区、细分和时期，判断来自哪些直接接触 |
| 企业内部 | 企业的经营流程、技术、资源、制度和决策 | 实际职责、参与环节、负责范围、接触的记录及任职时间 |
| 用户 | 生活或工作任务中的选择、购买、使用、体验与替代 | 使用、购买、付款和决策分别由谁承担，本人参与过哪些步骤 |

模式说明受访者与研究对象的关系。一个人可兼具不同位置，例如企业采购人员同时是员工用户；按题组注明他在回答哪段亲历。

进一步分工时，用实际工作确定可问内容：

| 角色位置 | 优先询问 |
|---|---|
| 高管或业务负责人 | 战略假设、业务组合、资源取舍、跨部门决定及重要异常 |
| 销售、渠道或客户运营 | 客户来源、产品与客群结构、赢单丢单、合作状态、续购与流失 |
| 财务 | 收入与成本分类、确认口径、经营表与财务表的对应、回款及现金约束 |
| 研发、产品或技术人员 | 任务要求、路线与指标、验证记录、进度、取舍及退出条件 |
| 工艺、制造、运营或供应链 | 工序、产能、良率、交期、质量问题、供应条件与扩张投入 |
| 人力或组织管理人员 | 实际人员投入、招聘与能力缺口、激励及团队协作机制 |
| 客户采购、预算或技术人员 | 需求与预算、指定权、选型和否决、合同、验证、验收与付款 |
| 实际使用者或一线执行者 | 日常任务、具体使用、变通办法、工作交接、实际收益与损失 |
| 供应商、实施或合作方 | 自己承担的环节、交付与配合、结算、依赖条件及合作变化 |
| 外部比较角色 | 自身熟悉范围内的替代方案、行业常态、客户条件及失败案例 |

区域负责人先回答辖区事实，离职人员先限定其任职时期；超出范围的信息作为间接了解记录，并寻找更知情角色。推荐来源、交易关系和利益位置用于理解样本覆盖及可能偏向。

## 4. 把受访者定义写成可筛选的经历条件

先说明为回答本轮核心问题，受访者应亲自参与什么、参与到哪一阶段、经历发生在何时及何种组织或场景。行业头衔、职级和知名度只是线索。

从下列问法选出必要的简短甄别题，并写出每题对应的纳入条件：

- “您最近在哪类项目中承担过哪些工作？能否用一个项目说明您负责的环节？”
- “这次采购从需求到使用，您实际参与过哪些步骤？哪些决定由其他人负责？”
- “您讨论这个技术或经营指标时，直接看过哪些测试、系统记录或业务资料？”
- “您能覆盖哪些地区、产品或客户类型？最近一次直接接触是什么时候？”
- “本轮几个主题中，哪些可以深入讨论，哪些需要提前准备，哪些更适合由其他同事回答？”

排除或改派条件写具体：经历不涉及核心环节、时期或场景不匹配、没有所需使用或购买经历，或只能复述公开介绍。只掌握部分主题者可承担对应题组；间接了解者可提供线索，不承担必须由亲历核实的事实。

按任务补充差异样本，例如成交与未成交、持续使用与停用、标准项目与交付失败、企业推荐与独立找到的对象。选哪一类应能说明它补充哪项判断。

## 5. 同一项目保留共同主题，按角色分配具体问题

多角色任务建立简表：`研究问题｜拟取得的事实或判断｜优先知情角色｜补充核对角色｜共同定义与期间｜对应题组`。简单任务可用一句分工说明。

| 共同主题 | 各角色的取证分工 |
|---|---|
| 增长是否可实现 | 高管讲假设与资源；销售拆客户、量价和订单；财务核收入与回款；客户核采购计划；研发和供应侧核交付条件 |
| 采购是否产生价值 | 采购方讲预算与选择；使用者讲任务完成和变通；供应方讲交付与续购；共同围绕同一产品、项目和使用时期 |
| 技术是否形成可用产品 | 研发讲实测与工程取舍；制造讲稳定性和产能；客户讲需求阈值、验证和拒收条件；专家比较替代路线 |
| 制度为何有效或失灵 | 高管讲目标和制度；主管讲资源与交接；一线还原实际事件、冲突和反馈；对齐同一工作流程 |

共同保留对象、时段、分类和关键指标，问法按角色的语言与经历变化。例如同问续购价值，使用者回答工作结果，采购人员回答预算与替换决定。

先让各方独立描述，再追问差异；比较前先查是否为项目、范围或阶段不同。把尚不能解释的冲突保留为下一轮问题，并明确更适合的角色或材料。

## 6. 根据访谈阶段改变准备与问题范围

- **初访探索：**确认职责与接触范围，从定义、近期实例和实际流程建立主线，再追机制、差异和量级，整理后续需要找的人与材料。
- **验证型初访：**已有具体资料时，简要确认知情基础后直接进入关键主张、异常或预测条件，以事实过程和记录支撑判断。
- **补访：**读取前访记录及其待核清单，逐项写出尚缺什么、新增材料是什么、准备澄清哪处差异；只保留理解新问题所需的背景。
- **追踪访谈：**沿用原有指标定义、对象范围和比较期间，追问前次计划进展、变化原因及新条件；指标变动时先建立新旧对应。
- **问卷后解释：**先读问卷题目、对象、样本口径和具体结果，选需要解释的差异或异常；先询问受访者自身经历，再展示相关发现，追支持、不符合的情况及可解释差异的条件。

交给问题编写环节的内容应包括：具体研究目标、已读材料与关键待证事项、受访模式和经历条件、各角色共同主题及分工、本轮是初访还是补访。具体问法与证据口径见[提问与追问方法](提问与追问方法.md)。

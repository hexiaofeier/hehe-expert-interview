# 用户访谈与产品体验

涉及个人使用、家庭决策、用户流失、产品试用或群体讨论时读取。先选与本次研究问题有关的经历分支和活动，再写提纲；模块顺序、分钟预算和主持稿编排见[提纲编排与主持.md](提纲编排与主持.md)。

## 一、按真实事件确认角色

围绕本次要研究的产品、服务或任务，确认谁提出需要、谁比较方案、谁决定购买、谁付款、谁实际使用。一个人可以承担多个角色，同一个家庭或组织也可能由多人分担。

| 角色 | 适合取得的信息 | 可直接使用的起问方式 |
|---|---|---|
| 购买或选择参与者 | 信息搜集、比较过程、决策转折、购买渠道与交付 | “请讲讲最近一次选择这类产品的经过，您主要参与了哪些事？” |
| 最终决策者 | 接受或否决方案的条件、参与者之间的取舍 | “最后是怎样确定这个方案的？当时谁的意见影响最大？” |
| 付款者 | 实际支出、预算来源、支付约束、续费决定 | “这次费用由谁支付？确定这笔支出时考虑了什么？” |
| 实际使用者 | 具体任务、操作过程、结果、困难、变通与继续使用 | “请选最近一次使用，讲讲当时要完成什么、实际怎样做的。” |
| 家长或照护者 | 家庭安排、陪伴监督、购买条件、观察到的变化 | “最近一次陪孩子使用时，您做了什么？孩子自己做了什么？” |
| 儿童或学生 | 自己的兴趣、参与感、理解与操作、喜欢和受挫的经历 | “上一次你用它做了什么？可以带我看看你当时怎么做吗？” |

家长对孩子的观察、孩子的自述和现场行为分别记录。孩子喜欢、家长认为有价值、家庭愿意付款是不同结果，需要向对应角色追问。
企业员工可能清楚使用情况却不了解采购费用；家庭付款者可能很少使用产品。向其确认知情范围，把缺口留给亲历者。
甄别条件写成可核对的行为与时间范围，例如近期是否购买、是否完成过指定任务、由谁决定；“资深”“喜欢分享”等形容词不足以确定经历。

## 二、按经历状态分流

先明确状态相对于哪个产品或服务、采用哪个时间范围，再确认当前状态和重要过往经历。目标产品的流失用户也可能正是竞品用户，提纲可组合相关分支。

| 经历状态 | 优先追问的实际内容 | 条件分支与共同主题的接法 |
|---|---|---|
| 已购买且正在使用 | 采用触发、实际选择、最近使用、预期与结果、维护、续用 | 使用很少时追最近一次和闲置原因；续用意向联系已有结果与替代方式 |
| 从未购买，也未认真考虑 | 目前怎样完成任务、何时遇到困难、是否需要改变 | 先了解现有做法；对没有发生过的购买过程，转问尚未行动的原因 |
| 考虑过但未购买 | 最近一次了解、比较到哪一步、放弃或延迟的节点 | 区分需求不强、条件未满足、方案不合适和当时没有购买权限 |
| 试用后未转化 | 试用任务、尝试程度、得到或没得到的结果、结束后的做法 | 没完成试用时先问为何中断；完成试用后再问正式购买的具体阻碍 |
| 已停用、退订或流失 | 最后几次使用、决定离开的过程、实际替代、离开后的结果 | 区分主动放弃、需求结束、被迫更换和短暂停用，再探索回归所需条件 |
| 正在使用竞品或其他替代方式 | 自己的真实选择、实际表现、继续使用的原因、换用经历 | 确认是否接触过目标产品；比较亲历内容，未体验部分另作概念反应记录 |

这些分支保留与研究问题有关的共同主题：任务与触发、原有做法、信息与参与者、关键取舍、实际结果及当前约束。共同主题不要求逐字使用同一道题。
例如研究“为何没有继续采用”，已有用户问持续使用的条件，流失用户问离开节点，试用未转化者问试用到购买之间发生的事，未考虑者问现有方式为何足够。
重度、低熟练、低参与或强分享意愿样本按研究用途选择，并说明其能帮助理解哪类经历；不要把某一类画像直接写成全部用户。

## 三、用具体事件建立共同主线

先让受访者选择最近一次或最能说明问题的一次事件，再按本次重点追问。下面是可裁剪的主线，不是每场必须完成的全流程。

1. “请讲讲最近一次处理这件事的经过。”追问当时想完成什么、地点和参与者；如果考虑过改变原方式，再追触发原因。
2. 如果曾寻找可选办法，问“您最初怎么了解可选办法的？”追问实际看过、问过或试过什么，以及哪些信息改变了判断。
3. 如果比较过方案，问“请讲讲最后确定方案前的一次比较。”追问保留和放弃了什么、谁参与、哪一刻作出决定。
4. 选定并实际采用后，问“第一次真正用起来是什么情况？”追问实际任务、得到的帮助、未达到预期之处及处理办法。
5. 已有使用经历时，问“后来有没有一次让您决定继续用、少用或换掉它？”追问具体结果、替代方案与后续变化。

用户先说一般态度时，接“能讲一次实际发生的情况吗？”；事件与一般判断不一致时，接“刚才这次有哪些特别条件，影响了您的选择？”
涉及变化时保留原方式、使用条件和其他同时发生的改变。自述“变好了”可用于理解感受与归因，还需问其看到的具体表现。
多设备、多产品或多场景研究先列实际使用清单，再挑与研究问题相关的场景深挖，避免逐个重复整套生命周期问题。

## 四、先探索未提示的需要，再展示产品信息

先问当前任务、已有办法、自然想到的选择及希望改善的地方，记录受访者自己使用的词。随后按研究目的出示品牌、功能、概念或价格材料。
已有用户会提到正在使用的品牌；主持人控制新提供的名单、卖点和评价框架的展示时点，保留受访者原来的认知。
出示新功能前可问：“您现在遇到这件事时通常怎样处理？”展示后再问：“如果用刚才这个办法，您会把它放在原来的哪个环节？”
概念材料写清适用对象、能完成的事和必要使用条件，统一呈现内容。概念尚未实现的能力按设想介绍，保留受访者对说明本身的理解检查。
先让受访者用自己的话解释看到了什么，再追吸引、疑虑、替代和取舍；发现理解偏差时记录最初理解，随后给出统一澄清。
价格披露前后的评价分别保留。若研究确需比较品牌或价格影响，在设计中明确各阶段展示什么，并记录受访者在哪个阶段作出选择。

## 五、把试用设计成可观察的真实任务

只在需要理解操作、体验或选择差异时加入试用。先写清要观察哪项任务、用哪个样品或版本，以及完成或中止任务后需要取得什么材料。

| 活动要素 | 提纲中要写出的操作 |
|---|---|
| 任务与起点 | 用受访者熟悉的目标描述任务，例如把一份材料交给指定对象；说明从哪个页面、设备或实物状态开始 |
| 标准介绍 | 为所有受访者准备同一段必要说明；区分测试自然发现能力与测试介绍后的使用体验 |
| 初次尝试 | 请受访者先按自己的理解操作，观察其先看哪里、怎样选择、何处犹豫、怎样判断完成 |
| 帮助规则 | 写明何时可以澄清任务、何时给操作提示、何时演示；记录提供帮助的时点、内容及随后表现 |
| 观察与追问 | 记录实际动作、错误、绕行、求助及结果；任务后回到具体节点问“刚才这里您在想什么？” |
| 结束条件 | 写明什么算任务完成、达到预留体验时间或受访者希望停止时怎样收尾，并转入体验回顾 |

任务中要求持续说出想法可能改变自然操作；依据研究重点选择边做边讲或任务后回顾，并在提纲中注明。
比较多个样品时使用相当的任务与必要说明。按受访者或小组轮换展示次序，例如分别先体验甲或乙，并记录实际次序；需要先学习基础操作时，说明这一共同前置步骤。
样品外观、品牌露出、可用功能或体验环境不同，先写清差异和对比较的影响。体验不完整的部分转问理解与预期，不混作完成使用后的评价。
单品回顾后再作横向取舍：“如果只能保留一个来完成刚才的任务，您会保留哪个？要放弃的另一个有什么仍让您在意？”追问选择条件和代价。

## 六、探索有条件的采用与购买

把购买问题接回真实任务和现有替代：“如果下次仍遇到刚才的任务，您会继续原来的办法，还是考虑这个方案？为什么？”
表示愿意时追问预计用在何时、由谁决定或支付、还要确认什么，以及会替代什么支出或做法；表示不愿意时区分没有需要与方案、价格、权限或条件不合适。
试用评价、推荐同事、申请公司采购和个人付款分别提问。家长愿意买与儿童愿意持续用也分别保留。
探索价格时联系实际预算、曾经支付的费用和替代方案；采用价格或配置变化情境时，每次说清改变的条件，再问选择是否变化及原因。
购买意向保留为该条件下的自述，并记录犹豫与未知条件；后续判断真实转化需要实际行为材料。

## 七、按访问形式改变活动

| 形式 | 适合的研究任务 | 实际活动与主持安排 |
|---|---|---|
| 个体深访 | 还原个人决策、连续任务、私密经历或细致操作 | 沿一个真实事件追深，可请本人演示或使用资料辅助回忆；把旁人的意见与本人经历分开 |
| 焦点小组座谈（FGD） | 观察表达差异、比较理解与取舍、讨论共同场景 | 需要个人初始反应时先各自记录，再轮流说明；讨论后追不同条件与少数意见，主持人管理发言和样品流转 |
| 亲子配对访谈 | 同时理解家庭决策、陪伴关系和儿童体验 | 分别给孩子与家长可回答的问题，再观察共同活动；让孩子先展示自己的做法，家长补充其亲历部分 |

FGD中的附和、争论和沉默本身值得记录；关键主题请成员讲自己的例子，不把小组最后达成一致当作全部用户的分布。
亲子访问先判断年龄、表达能力和活动耐受度，选择口述、演示、摆放或简单选择等合适方式。家长抢答时请其稍候，先让孩子完成，再听家长观察。
涉及孩子不愿在家长面前说的体验时，依据项目已确认的参与安排设计分段交流；允许不回答，记录无法了解的部分。
产品把玩、概念卡排序和取舍活动按研究目标选择，各自给出动作、要回答的问题与记录方式；不为活跃气氛堆叠活动。

## 八、场景材料与必要观察

照片、日常时间线和本人演示用于找回具体情境，提前说明需要哪类材料及用途，让受访者选择愿意展示的内容。
记录照片或演示来自哪次事件、是否典型、有哪些画面外条件；将过去场景的回忆与当前现场观察分开。
如需入户，可补充“观察空间与物品—请本人演示任务—围绕所见追问”的安排，明确进入区域、参与者和拍摄范围，记录环境怎样影响行为。
入户执行前走查实际任务与场地安排，试访后调整观察、演示与交流所需时间。

## 九、交稿前按本次任务核对

逐条走通受访者的实际经历：谁回答、何时启用、此前是否已有必要信息、活动结束后能得到什么。没有发生的行为转问真实替代和未行动原因。
检查不同分支是否仍能围绕共同主题比较，儿童、付款者与使用者的材料是否保留来源，未提示回答是否在展示材料之前取得。
检查体验任务是否含明确起点、统一介绍、帮助规则、观察与回顾，比较与购买问题是否交代条件。再将实际活动交给编排参考核算时间。

# 提纲编排与主持

将已有问题整理为可直接执行的提纲，或根据预访、前几场访问与材料反馈修订时读取。用户经历分支和体验活动内容见[用户访谈与产品体验.md](用户访谈与产品体验.md)。本参考负责顺序、时间、现场提示与迭代。

## 一、先确定本轮要取得什么

从本次研究重点中选出必须在访谈内解决的问题，写清本轮结束时希望取得的具体事件、过程、数字口径或判断依据。
把已有材料能够回答的背景放到访前准备；访谈用于核对重要差异、补足缺口和取得具体经历。参与者定义、职责与经历确认保留必要核验。
研究范围明显超过一次访问容量时，建议减少次要主题、提前准备材料或分轮访问，并说明每轮支持什么决定；不要靠压缩所有回答时间保留整份题库。
按对象的经历和谈话逻辑安排模块。常见顺序是开场与经历确认、具体事件、重点深挖、比较或材料讨论、补问与收尾，可依据任务调整。
需要未提示的认知或需求时，将品牌名单、功能说明、概念和价格展示安排在相关探索之后，并写清展示的起止位置。

## 二、把问题编成现场可用的模块

每个模块写目标、分钟预算和优先级，再放可说出口的主问、视回答启用的追问及必要主持动作。简单模块可用短段落表达，不必给每道题重复所有字段。

> **模块：最近一次选择经历。目标：找到方案改变和最终决定的节点。预算：本例12分钟。优先级：必问。**
>
> **主问：** “请选最近一次为这项工作选择工具的经历，从最初出现需要讲起。”
>
> **条件追问：** 如果比较过多个方案，问“哪一次比较改变了您的想法？”；如果直接沿用原方案，问“当时什么让您决定继续用原来的？”
>
> **主持提示：** 先听受访者完整叙述，再补参与者与时间点。已经说清的内容作标记，后续相关模块只追缺口。

主问一次提出一个可理解的任务。多个相关核对点放在条件追问中，写清什么回答触发什么追问；研究者提示不作为一长串问题念给受访者。
各模块之间加必要承接，例如“刚才了解了选择过程，接下来想看您实际怎样用它完成一次任务”，让对象和话题转换清楚。
确定贯穿本场的具体事件及当前阶段。需要从原采购切到本轮续约、从首次使用切到最近使用时，交代两次事件各自的时间与关系；后续实施、使用、复购或下一轮任务尚未发生时，转问当前状态、阻碍或未来条件。
对不同身份或经历标出进入和离开的条件，如“仅问参加过试用者；未试用者转入现有做法”。跳转后仍能找到共同主题与收尾。

## 三、按真实谈话与活动核算时长

先确认总时长，再分配模块分钟数，包含开场说明、材料操作、补问和结束。预算加总应与总时长一致；范围不同的版本分别列预算。
以下是一对一访问、含一个短体验任务的60分钟示例，展示取舍方法。题目、活动和时长需依据本次目标重新安排。

| 模块 | 目标 | 分钟 | 优先级与取舍 |
|---|---|---:|---|
| 开场与经历确认 | 说明安排，确认实际角色及相关经历 | 5 | 必要说明保留，已取得的背景简要核实 |
| 最近一次实际事件 | 找到任务、原方式和关键节点 | 12 | 保留一个完整例子，第二个例子视需要加深 |
| 本次重点深挖 | 核实关键困难、结果及影响条件 | 13 | 优先回答本轮最重要的缺口 |
| 单项任务体验 | 取得实际动作、帮助与结果记录 | 18 | 统一说明2分钟、任务10分钟、回顾6分钟 |
| 比较与有条件选择 | 联系替代方案及采用条件 | 8 | 先取得核心取舍，再追次要配置 |
| 补问与结束 | 澄清关键遗漏，确认后补事项 | 4 | 预留，不以追完题库挤占 |
| 合计 |  | 60 | 5＋12＋13＋18＋8＋4＝60 |

上述加总只说明预算一致。是否容纳真实访谈，需要结合问题深度、人数、任务和试访表现判断。

| 实际占用 | 设计时怎样处理 |
|---|---|
| 具体事件叙述与追问 | 预留受访者回忆、讲述、主持澄清及核对时间；核心事件多时相应减少其他主题 |
| 多人逐个回答 | 按人数估算个人表达，再加回应、追问与换人时间；例如六人各讲两分钟已占12分钟 |
| 样品体验与换样 | 将领取、必要说明、实际体验、换样或复位、个人记录及比较分开核算 |
| 亲子共同活动 | 计入孩子理解任务、尝试、家长补充、重新集中注意及必要休息 |
| 远程屏幕演示 | 计入共享屏幕、找到文件或页面、切换设备、检查声音画面与恢复任务的位置 |
| 旁听问题交接 | 约定汇总、筛选和交给主持人的时点，放进补问预算 |

不要用关键词数量、题目数量或预设的平均读题速度声称时间已经验证；主要占用通常来自回答、操作和互动。
需要可行性依据时，选核心问题和关键活动进行口头走读或试访，记录实际用时、未完成环节及删改决定。未试访时如实写为设计预算。
座谈与配对访问分别核算，不能把一对一模块时间直接复制过去。材料数量增加时，同步调整体验、单品反馈与比较时间。

## 四、让优先级真正指导取舍

用“必问”“有相应经历才问”“时间允许时加深”等清楚说明标记，不必给所有题设置同一套符号。
必问内容承接本轮决策问题和跨访共同比较项；条件问题承接实际经历；加深问题用于解释已出现但尚未清楚的差异。
为接近超时时写出具体取舍，例如保留一个完整失败例子，跳过第二个相似例子；保留核心取舍，减少次要功能逐项评价。
删去备用题后，再检查必问本身能否展开。需要连续拆多张表、还原多个事件或解释多个预测时，先选最影响本轮判断的一项深入，其余明确转为访前准备、书面补充或下一轮，并说明各自需取得什么。
出现重要新线索时，主持人可调整后续顺序或深度，同时记下未完成的共同项。需要更多时间或其他角色时转为后续核对，不在现场无限展开。
收尾优先澄清会改变判断的歧义，再问“还有什么与今天主题有关、我们没有谈到的情况？”最后确认可提供的资料和后续联系安排。

## 五、分清主持执行版与受访者阅读版

主持执行稿包含研究用途、对象与经历分支、模块目标和时间、主问、条件追问、材料展示与记录提示。访前材料中的已知信息可附简短出处或页码，便于主持核对。
已有回答、未验证的假设和待核矛盾放在主持提示中，并改写成中性的口头问法；清楚区分“材料中写了什么”与“现场需要核实什么”。
完整设计时同步整理受访者阅读版，供访前了解要回答什么、判断自己能否回答并准备。按主题写出完整的主要问题、预计时间、希望回忆的事件及可准备的资料；不能只剩主题名或含糊短语。
阅读版使用对方能理解的称谓，保留产品、业务和相关经历的必要背景；内部研究判断、他方敏感材料、主持疑点与完整追问树留在主持执行版。
需要取得未提示的认知、需求或选择时，阅读版只说明相关主题及现场讨论安排，品牌、概念卖点、价格选项和候选解释按原设计到现场再展示。其他不影响研究顺序的主要问题正常提前提供；确需预读材料时写明版本及其对后续提问的影响。
数据请求可单列定义、时期、单位和可接受形式。对方只能提供区间、汇总或解释时，注明希望如何补充，不把资料准备要求写成已获同意。
两版沿用同一对象、核心研究主题与时间安排，主问题可以按各自读者改写合并。多角色的阅读版分别整理；临时调整重点后同步受影响的阅读版，主持执行版的详细追问与记录工具完整保留。

## 六、把开场与敏感安排写成真实动作

开场简短说明研究者身份、交流用途、预计时长、主要形式、资料使用范围，以及录音或旁听的实际安排，再确认受访者是否理解并愿意开始。
录音前确认项目是否计划录音、如何使用和谁会接触，并取得相应同意；尚未确定的安排列为访前待确认事项。删除期限、公开引用或会后确认按能够履行的安排表述。
对方不愿录音时，按项目允许的笔记或其他记录方式调整；需要实名引用、材料转交或后续展示时，单独确认相应范围。
涉及支出、预算、经营数据或个人经历，可先说明为什么需要，邀请提供其能够披露的层级。确数不便时追区间、比例、变化方向、匿名例子或可后补资料。
问题超出其知情范围时，确认谁更了解或有什么材料可核对。对方不愿展开时保留已取得内容和缺口，继续其他主题。
儿童、家长与旁听人员的参与方式按项目已确认安排写清。现场出现新增人员时，先确认其角色及对交流和记录的影响。

## 七、写出必要的主持提示

| 场景 | 可执行的主持动作 |
|---|---|
| 回答停留在一般评价 | 请其选一次具体事件，再追当时的动作、参与者和结果 |
| 受访者提前谈到后续主题 | 顺势听完并标记已覆盖内容，之后只补缺口 |
| 说法与材料或前述回答不一致 | 指明差异，温和询问是否因对象、时期、口径或条件不同 |
| 小组一人持续主导 | 简短复述其要点，再邀请尚未发言者讲自己的经历，并留出回应时间 |
| 讨论快速形成一致 | 需要个人判断时先独立记录，再请不同选择或不同条件者说明原因 |
| 家长替孩子回答 | 请家长先听孩子说或演示，再补充本人观察到的情况 |
| 演示卡住或偏离任务 | 依据事先帮助规则澄清或提示，记录介入后从哪里继续 |
| 客户旁听提出新题 | 由约定人员汇总，主持人判断与研究重点的关系，在预留时段补问 |
| 回答明显跑题 | 承接与本轮有关的信息，说明要返回的具体问题，必要时登记为后续线索 |

主持提示写成现场动作，追问内容写成能口头说出的句子。示例答案、备选解释和观察点不用逐项提示给受访者。
展示材料注明编号或名称、版本、展示时点、是否需要统一说明及记录位置。远程演示同时写明由谁共享、出问题时如何回到访谈或改用材料回顾。
需要照片、截图或演示片段时，事先确认可展示和记录的范围；现场记录与提纲对应到题目、材料或任务，便于访后查找。

## 八、用预访和前几场修订提纲

预访或前几场后，查看哪些主问理解不一、对象答不上、例子不具体、内容重复、跳转失效或活动超时；根据实际反馈调整。
修订先解决具体问题，例如把抽象评价改为最近事件、将采购预算转给实际知情角色、减少相似样品或给远程操作增加时间。
保留与研究问题有关的共同主题、关键定义和必要核心题。确需改变时，记录哪个版本从何时使用、为什么改、会影响哪些访谈之间的比较。
用简表记“原安排—现场发现—修改—后续需要观察的变化”。这里记录设计改动，不代替逐字稿整理、材料验收或分析结论。
刺激物版本、展示顺序、帮助规则和录音方式改变时，也纳入实质变更记录；只改错字可按通常版本维护处理。
后续访问检验修改是否更容易取得所需信息、是否减少重复或恢复时间容量，仍有问题再针对性修订。

## 九、把补访集中到剩余缺口

先读对应访谈记录和待核材料，写明已经知道什么、还缺哪一个事实或解释、应由原受访者还是其他角色回答。
补访开头用简短背景帮助回忆，再直接进入未清事项，例如核对一个口径、补齐一次事件的中间环节、解释材料差异或增加重要反例。
为每个补访题注明触发材料或先前回答的位置，口头提问只保留对方理解所需的上下文；不要重新访问整套公司或个人背景。
新增问题若关系到跨访共同比较，判断哪些先前访问也需补充，并说明补访优先级和原因。无法补齐的部分保留缺口及比较限制。
完成稿件后走通一个实际角色和一条条件分支，核对顺序、分钟加总、材料交接、记录动作及收尾；内容可执行与文件格式分别检查。
